# Arsitektur

Website ini menggunakan React sebagai lapisan antarmuka dan Vite sebagai development server serta bundler.

- `src/App.jsx` menyusun seluruh section halaman.
- `src/main.jsx` melakukan render React ke elemen `#root`.
- `css/style.css` menyimpan design system dan style responsif.
- `assets/images` menyimpan foto tim.
