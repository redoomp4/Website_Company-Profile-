# Panduan Pengembangan

1. Pasang dependensi dengan `npm install`.
2. Jalankan server lokal melalui `npm run dev`.
3. Jalankan `npm run build` sebelum membuat rilis untuk memastikan bundel produksi berhasil dibuat.

Gunakan komponen dan class yang sudah ada agar tampilan tetap konsisten pada desktop maupun mobile.
